# Slovenian Speech Dataset - 10+ hours
Dataset comprises **10+** hours of audio recordings featuring **20+** speakers engaged in telephone dialogues in the Slovenian language. It contains speech data designed for training robust **language models** and **automatic speech recognition** systems in real-world conversational scenarios. - **[Get the data](https://unidata.pro/datasets/slovenian-speech-recognition/?utm_source=github-nlp&utm_medium=referral&utm_campaign=slovenian-speech-recognition)**
